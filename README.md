# Rhythm Maker - Keyboard Editor

Rhythm Maker の開発用プロジェクトです。HTML / CSS / JavaScript で動作します。Pythonは使っていません。

## 起動方法

1. ZIPを展開します。
2. フォルダを Visual Studio Code などで開きます。
3. VS Code の拡張機能「Live Server」を使い、`index.html` を右クリックして「Open with Live Server」を選びます。
4. ブラウザのアドレスが `http://127.0.0.1:...` または `http://localhost:...` になっていることを確認します。

JavaScript の ES Modules を使っているため、`index.html` のダブルクリック（`file://` で開く方法）では動作しません。

## キーボード操作

| キー | 操作 |
|---|---|
| `D` | レーン1にノーツを置く / 消す |
| `F` | レーン2にノーツを置く / 消す |
| `J` | レーン3にノーツを置く / 消す |
| `K` | レーン4にノーツを置く / 消す |
| `←` / `→` | 配置位置を左 / 右へ移動 |
| `↑` / `↓` | 前 / 次の小節へ移動 |

各レーンの左側にレーン名と対応キーを表示します。先にマス目をクリックするか `←` / `→` で縦のカーソルラインを移動し、その位置で `D`・`F`・`J`・`K` を押します。マス目をクリックしただけではノーツは置かれません。

左側の「ノーツの種類」でタップ / 長押し / 消しゴムを切り替えます。消しゴムを選んでから D・F・J・K を押すと、そのレーンのカーソル位置にあるノーツを削除します。ツール選択・BPM変更・グリッド変更のあとも、エディターにフォーカスが戻ってキー操作を続けられます。

## 機能

- 4レーン譜面エディター
- キーボード（D/F/J/K）でレーンを指定してノーツ配置
- 縦カーソルラインで配置位置を確認
- 左右キーで配置位置を移動
- 上下キーまたは画面の矢印ボタンで小節を移動
- タップノーツ / 1拍ぶんの長押しノーツ / 消しゴム
- BPM設定（30〜300）
- 4分 / 8分 / 16分のカーソル移動間隔
- 1小節あたり最大36ノーツ
- 元に戻す / やり直す
- 小節ごとのクリア
- 複数小節のTXT読み込み / 書き出し（時間は曲全体の先頭からのミリ秒）
- BPM・レーン・位置・重複・長押し・ノーツ上限のデータ検証
- MP3 / WAV 読み込み、音源再生、一時停止、停止
- 音源波形表示とクリックでのシーク
- BPMと開始オフセットに基づく譜面との同期
- IndexedDBへの譜面・音源保存と復元

## TXT形式

4列形式を維持しています。`time_ms` は小節ごとにリセットせず、曲全体の開始からの時間です。小節が進んでも、以前のScratch向け4列フォーマットを利用できます。

```text
# RHYTHM_MAKER
# BPM:120
# LANES:4
# MEASURES:2
# AUDIO_OFFSET_MS:0
# time_ms|lane|type|duration_ms
0|1|tap|0
500|2|tap|0
2000|3|hold|500
```

## コードを増やすときの約束

- 大きな変更の前にフォルダをコピーしてバックアップを作ってください。
- 新機能はできるだけ新しいファイルに分けます。
- 既存コードを変更するときは、変更するファイル名と変更箇所を確認してから進めます。
- ボタンのイベント処理は `js/events/button-events.js`、キーボード処理は `js/events/keyboard-events.js` にまとめています。
- ChatGPTに修正を頼むときは「ファイル全体を置き換えず、変更箇所だけを差分で教えて」と伝えてください。
- 自分で変更したコードを送るときは、そのファイルの最新版を送ってください。

## Ver. 3.0 / 3.5 追加機能

### 音源
- MP3 / WAV / WAVE の読み込み
- 再生 / 一時停止 / 停止
- 波形表示（Web Audio API の decodeAudioData を利用）
- 波形をクリックして再生位置を移動
- BPMに基づいて再生位置から小節・16分位置を計算し、譜面エディターを追従
- 譜面開始オフセット（-5000〜5000 ms）を設定可能
- 音源はHTMLAudioElementで再生し、波形解析ができない環境でも再生を試みます

### データ管理
- Scratch向けTXTを書き出し / 読み込み
- TXTヘッダーに `AUDIO_OFFSET_MS` を追加（従来の4列ノーツ形式は維持）
- IndexedDBに譜面と読み込んだ音源を保存
- 保存したプロジェクトの読み込み
- 起動時に前回保存したプロジェクトを自動復元
- 譜面データ検証（BPM、レーン、配置位置、重複、長押し、1小節36ノーツ制限）

### 同期の考え方
- 1小節は4拍として扱います。
- 1拍の時間は `60000 / BPM` ミリ秒です。
- 音源の再生時間からオフセットを引き、BPMに基づいて小節と16分位置を計算します。
- オレンジ色の線が再生位置、水色の線がノーツ配置カーソルです。
- 波形をクリックすると音源をシークし、その位置に譜面エディターが追従します。

### 保存について
「このブラウザに保存」は IndexedDB に保存します。同じブラウザ・同じサイトの保存領域で利用できます。ブラウザのサイトデータを消去すると、保存した譜面や音源も消える場合があります。大切な譜面は必ずScratch向けTXTも書き出してバックアップしてください。
